# ONG Esperança

Projeto web desenvolvido durante a disciplina de Desenvolvimento Front-end, com o objetivo de criar uma aplicação para apresentar a ONG Esperança, seus projetos e possibilitar o cadastro de pessoas interessadas em participar de suas ações.

## 📌 Sobre o projeto

A ONG Esperança é uma aplicação web desenvolvida com HTML5, CSS3 e JavaScript.

O projeto foi construído inicialmente como uma interface estática e posteriormente evoluído para uma aplicação com navegação dinâmica utilizando JavaScript e o conceito de SPA (Single Page Application).

Nesta etapa, o projeto também passou a utilizar Git e GitHub para controle de versões, seguindo uma organização baseada no GitFlow.

## 🎯 Objetivo

O objetivo da aplicação é apresentar informações sobre a ONG, seus projetos e disponibilizar uma área de cadastro para pessoas interessadas em participar das iniciativas.

Além do desenvolvimento da interface, o projeto busca aplicar conceitos de organização de código, responsividade, acessibilidade, versionamento e documentação técnica.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
